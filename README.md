# Professional ToDo Manager

A professional desktop To-Do Manager built using Python and SQLite.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Organize tasks using categories
- Set task priority
- Store tasks permanently using SQLite
- Simple and professional graphical interface

## Technologies Used

- Python
- Tkinter
- SQLite
- Object-Oriented Programming
